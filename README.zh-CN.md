# Flow 下载工作台

**基于 Rust、egui 和 librqbit 的 Windows BitTorrent 与 HTTP(S) 下载软件。**

[English](README.md) · 简体中文

<img src="assets/flow-icon.png" alt="Flow 图标" width="112" />

双击一个程序即可同时启动桌面界面和内置下载引擎，不需要安装 Python 或单独启动后端服务。

## v0.3.0 更新

- 自动识别常见音视频文件，右键下载任务即可播放或边下边播。
- 默认仅打开视频窗口，带鼠标控制栏；额外的 Flow 控制面板按需手动打开。
- 支持字幕、音轨、倍速和本地播放位置记忆。
- 修复暂停/继续状态同步，包括校验期间点击继续后仍停留在暂停状态的问题。

## 功能

- 磁力链接、本机 `.torrent` 文件，以及原生文件和文件夹选择器。
- 紧凑的任务列表，支持搜索、状态筛选、文件进度、对等连接和诊断日志。
- 暂停/继续、校验已有种子文件。
- HTTP/HTTPS 直链下载，服务端支持时可校验后断点续传。
- 种子文件选择下载，查看单任务或全部任务最近五分钟的速度曲线。
- 删除任务时可选择保留文件、删除未完成文件或删除任务全部文件。
- 关闭窗口后驻留系统托盘，继续后台下载。
- 右键复制磁力链接、原始来源、名称、保存路径，或打开下载目录。
- 双击任务名称或按 **空格** 切换暂停/继续；**Delete** 打开删除确认。
- 持久化保存默认目录、全局限速和连接数配置。
- 可编辑 Tracker 订阅、镜像切换、本地缓存、失败退避及定期健康检查。
- 按当前资源查询 Tracker 统计和评分，支持 DHT 节点持久化及引擎会话保存。
- 浅色/深色外观，内嵌多尺寸应用图标。

## 构建与运行

**直接使用成品：** 前往 [GitHub Releases 发布页面](https://github.com/wrench1997/flow/releases/latest) 下载 `Flow.exe`。发布附件同时提供 SHA-256 校验文件。

当前支持的桌面目标为 **Windows x64（MSVC）**。源码构建需要 Rust/Cargo，以及包含 Windows SDK 的 Visual Studio C++ 构建工具。

```powershell
git clone https://github.com/wrench1997/flow.git
cd flow
.\build-portable.ps1
.\Flow.exe
```

脚本会在项目根目录生成 `Flow.exe`，平时直接双击即可。`start.cmd` / `start.ps1` 是先构建再运行的开发快捷入口。

```powershell
cargo test --release --locked
cargo fmt --check
```

仓库仅包含源码和应用素材，**不包含可执行文件、下载内容、本机任务状态、缓存或临时文件**。Windows 版本静态链接 C/C++ 运行库，使用成品无需安装 Python、Rust 或单独的 Visual C++ 运行库。

## 设置与操作

顶部“设置”可修改默认目录和限速。`0` 表示不限速；限速立即生效，连接上限重启后生效。默认目录仅影响新任务，不会移动已有文件。

默认上传上限为 **512 KiB/s**。BT 任务完成后继续做种，暂停可停止上传。默认关闭窗口会隐藏到系统托盘，下载继续进行。双击托盘图标恢复窗口；右键托盘选择“退出并停止下载”可完全退出。在设置中关闭“关闭窗口后后台下载”，即可恢复关窗退出。

删除任务默认保留文件，也可选择删除未完成文件（含 HTTP 临时文件）或任务全部文件。文件删除是永久操作，不经过回收站；保留无关文件和目录。

需要选择种子文件时，添加任务勾选“添加后暂停”，等待元数据加载，在“文件”页勾选并应用后再继续。由于种子分片可能跨文件，未选文件仍可能写入少量共享分片数据。

HTTP 链接应直接指向文件，而非网盘分享页面。临时数据保存在目标目录的 `.flow-<id>.part`，成品文件名带短任务 ID 以减少重名冲突。安全续传要求服务器支持 Range，并提供 ETag 或 Last-Modified 校验信息；服务器忽略续传请求或缺少校验信息时，会从头重新下载。BT 与 HTTP 共用全局下载限速。

“速度曲线”页可切换当前任务与全部任务，显示本次运行最近五分钟的采样，不跨重启保存。

复用其他下载器的数据时，请使用匹配的种子和原保存目录。Flow 先校验再续传，并区分校验进度与下载进度；其他引擎的续传文件不能代替校验。

升级时先通过托盘菜单退出 Flow，再替换 `Flow.exe`，保留 `data/` 和下载目录即可。

## Flow 播放器（v0.3.0）

Flow 提供自己的播放控制面板，底层使用 mpv。从发布附件下载 `setup-player.ps1`，放在 `Flow.exe` 旁，首次执行 `./setup-player.ps1`，下载 [mpv 官网安装页](https://mpv.io/installation/) 列出的 Windows 构建；脚本固定版本并验证 SHA-256。播放内核保存在程序旁的 `runtime/mpv/`，不安装系统组件、不修改文件关联。

- 顶部“播放器”可打开本地音视频或 HTTP(S) 媒体直链。
- 磁力/种子任务加载元数据后自动识别 MP4、MKV 等常见音视频扩展名。右键任务选择“播放 / 边下边播”：单媒体文件直接播放，多文件弹出按大小排序的选择列表。“文件”页也保留单文件播放按钮。该操作会选中相应文件并继续任务。
- 播放默认只打开视频窗口，鼠标移入显示控制栏；额外的 Flow 面板通过顶部“播放器”手动打开。Flow 面板控制暂停、跳转、音量、倍速、全屏、字幕和音轨。播放位置记录在本地 `data/player-history.json`。
- BT 播放使用带鉴权的本机 HTTP 流，支持 Range 跳转和 librqbit 按播放位置调度分片；未下载的内容等待分片到达后再读取。
- 关闭控制面板不会停止播放，关闭画面窗口可停止播放；停止播放不会暂停下载。完全退出 Flow 会同时关闭播放器。

这是首版播放集成，视频尚未嵌入控制面板。缓冲取决于来源和下载速度，跳到未下载部分可能需要等待。暂不支持 DRM、分享页提取、光盘菜单或播放列表管理。迁移时请一起复制 `runtime/mpv/`。从 v0.3.0 开始包含播放器功能。

## Tracker 发现与容错

Flow 保留种子原有 Tracker，默认订阅 [XIU2](https://github.com/XIU2/TrackersListCollection) 和 [ngosang](https://github.com/ngosang/trackerslist) 的公开列表。这些项目提供地址目录，具体 Tracker 由不同运营者维护。

在 **Tracker → 订阅设置** 中可添加、编辑、停用或删除来源。每个来源支持最多五个 HTTP/HTTPS 镜像，按顺序尝试。全部失败或返回无效、空列表时，保留上次成功缓存。

- 默认每 **24 小时**更新列表，每 **30 分钟**检查未暂停任务，两项间隔均可调整。
- 失败后按指数退避延长重试间隔，最长 **6 小时**。
- 每个任务最多 **200 个 Tracker**，全局同时查询 **12 个**，单请求 **8 秒**超时。
- HTTP/UDP scrape 查询使用当前资源哈希，按查询历史、报告做种数和响应耗时评分。
- 私有种子不参与公开 Tracker 发现。

**后台维护只更新候选和评分，不会重启下载。** 新候选需要点击“应用候选”，目前该操作会重新加载任务并校验已有文件。

scrape 失败不代表 Tracker 无法返回下载来源。报告做种数不等于已连接人数，高评分不保证更快。公开种子还可通过 DHT 寻找来源，但没有可访问的用户持有所缺数据时，无法凭空补齐内容。

## 本地数据与迁移

运行数据保存在可执行文件旁的 `data/`：

| 路径 | 用途 |
| --- | --- |
| `settings.json` | 默认目录与传输设置 |
| `tasks-rust.json` | 任务目录和 Tracker 查询历史 |
| `tracker-sources.json` / `tracker-cache.json` | 订阅设置、列表缓存及重试状态 |
| `dht.json` | DHT 路由节点状态 |
| `<task-id>.http.json` | HTTP 传输与续传状态 |
| `rqbit/` | 引擎会话及续传状态 |
| `status.json` / `events-rust.jsonl` | 本机状态和诊断日志 |

迁移软件时一起复制 exe 与 `data/`，并确保原下载路径仍可访问。本机 API 使用随机环回端口和每次启动生成的 Bearer token；目录锁防止多个引擎同时使用同一状态目录。

## 项目结构

| 路径 | 职责 |
| --- | --- |
| `src/main.rs` | 桌面界面与操作 |
| `src/backend.rs` | 内置后端生命周期 |
| `src/engine.rs` | 下载会话、任务、持久化和本机 API |
| `src/http_download.rs` | HTTP 传输与续传校验 |
| `src/file_ops.rs` | 限定任务文件范围的删除操作 |
| `src/player.rs` / `src/media.rs` | 播放控制与 HTTP 字节范围读取 |
| `src/tray.rs` | Windows 托盘与后台运行 |
| `src/trackers.rs` | scrape 查询与评分 |
| `src/subscriptions.rs` | 订阅、镜像、缓存与重试策略 |
| `src/settings.rs` | 下载设置及校验 |
| `assets/`、`build.rs` | 图标和 Windows 资源嵌入 |

## Windows 下载提示

Flow 目前未进行代码签名。有用户报告本地预览版被杀毒软件删除，但尚未提供检测名称与被拦截的文件，原因仍未查明。发布新版不代表已确认误报；校验值只能确认文件一致性，不能证明安全。若被拦截，请保留检测记录用于排查，不要因此关闭防护。

## 当前限制

Flow 处于早期开发阶段，尚未实现软件自动更新和主题跨启动保存。HTTP 下载每个任务使用单连接，暂不集成浏览器登录/Cookie，也不从 Content-Disposition 提取文件名。磁力元数据仍需要可连接的对等节点，增加 Tracker 不能保证解析成功。应用新 Tracker 候选需要校验文件。对于 librqbit 未提供可靠数据的已连接完整做种者数、分布式资源可用率，界面显示未知。

基于 [egui](https://github.com/emilk/egui) 和 [librqbit](https://github.com/ikatson/rqbit) 构建。
